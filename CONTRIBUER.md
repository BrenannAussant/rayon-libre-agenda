# Comment contribuer

1. Forkez ce dépôt sur votre compte GitHub.
2. Clonez votre fork.
3. Créez une branche : ajout-VOTRE-PSEUDO.
4. Copiez benevoles/modele.md en benevoles/VOTRE-PSEUDO.md et remplissez-le.
5. Commitez, poussez la branche sur votre fork.
6. Ouvrez une Pull Request vers la branche main de ce dépôt.

Une seule fiche par personne. Ne modifiez pas les fiches des autres.
